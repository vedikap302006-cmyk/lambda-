AWS Lambda Cost Calculator

Description

This project demonstrates a simple serverless function using AWS Lambda and Python.

The function accepts two numbers as input and returns their sum.

Technology Used

- AWS Lambda
- Python
- GitHub

Input

{
    "num1": 10,
    "num2": 20
}

Output

{
    "num1": 10,
    "num2": 20,
    "sum": 30
}

Testing

The Lambda function was tested with different test events to verify that it correctly calculates the sum.

Test 1

10 + 20 = 30

Test 2

5 + 15 = 20

Test 3

100 + 250 = 350

Test 4

-10 + 25 = 15

Outcome

Successfully deployed and tested a serverless AWS Lambda function that performs addition without requiring a continuously running server.
